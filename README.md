# 🏫 The Legacy School Management System

## 📘 Overview
**The Legacy School Management System** is a comprehensive web and mobile-based solution designed to digitalize and streamline academic, administrative, and communication workflows in educational institutions.

It supports multiple user roles — **Admin, Teacher, Student, and Parent** — each with a dedicated portal for managing their respective operations.  
The system provides real-time access to attendance, results, fees, communication, and academic activities.

---

## ⚙️ Tech Stack

| Layer | Technology |
|-------|-------------|
| **Frontend (Web)** | ASP.NET (C#) |
| **Backend (API)** | ASP.NET Web API |
| **Mobile App** | React Native |
| **Database** | Microsoft SQL Server |
| **Version Control** | Git / GitHub |
| **IDE** | Visual Studio & Visual Studio Code |

---

## 🧩 Key Modules

### 🎯 Front Office
- Manage visitor logs, postal records, complaints, and admissions
- Dashboard with student and user statistics

### 👩‍🎓 Student Information
- Maintain student profiles, academic records, and class assignments

### 💰 Fees Collection
- Fee receipt generation, pending fee reports, and collection summaries

### 💼 Payroll
- Staff salary management and payslip generation

### 🕒 Attendance
- Daily student and staff attendance tracking
- Integration with mobile app for quick updates

### 📑 Reports
- Academic performance, attendance, and financial reports

### 🧪 Examinations
- Exam scheduling, marks entry, and results publishing

### 📚 Academics
- Class timetables, subject management, and teacher allocation

### 💬 Communication
- Internal messaging and circular distribution between staff, students, and parents

### 🏠 Homework
- Teachers can assign and evaluate homework through the web or app

### 📦 Inventory
- Track and manage school assets and supplies

### 💵 Accounts
- Income, expense, and ledger tracking for financial management

### ⚙️ Administration
- Role-based access control and configuration management

---

## 📱 Multi-Portal Access

| Portal | Description |
|---------|-------------|
| **Admin Portal** | Complete management access with dashboards and analytics |
| **Teacher Portal** | Attendance, exams, homework, and communication tools |
| **Student Portal** | Access to assignments, grades, schedules, and notices |
| **Parent Portal** | View student performance, attendance, and fee status |

---

## 🧠 Architecture Overview
- **Frontend (ASP.NET)** consumes RESTful endpoints exposed by the **.NET Web API**.
- **React Native App** interacts with the same API endpoints for cross-platform mobile support.
- **SQL Server** handles relational data with stored procedures and optimized indexing.
- **Authentication** is handled through secure role-based login, with future plans for **JWT integration**.
